---
description: Commita todas as alterações pendentes (sem push)
---

Faça um commit de tudo que está pendente neste repositório.

Regras:
- Use o git do GitHub Desktop se `git` não estiver no PATH: pegue o `git.exe` mais recente em `%LOCALAPPDATA%\GitHubDesktop\app-*\resources\app\git\cmd\git.exe`.
- Rode `status --short` e `diff` antes para entender o que mudou.
- Inclua arquivos novos e modificados (`add -A`), mas nunca ignore arquivos por conta própria.
- Mensagem em português, com nome expositivo e descrição curta no corpo (o que mudou e por quê).
- Se as mudanças forem de assuntos muito diferentes, separe em commits pequenos em vez de um único commit.
- **Não faça push.** Apenas commite e mostre o hash e o resumo.
