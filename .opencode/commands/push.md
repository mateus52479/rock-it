description: Envia os commits locais para o remoto
---

Envie os commits locais da branch atual para o remoto.

Regras:
- Use o git do GitHub Desktop se `git` não estiver no PATH: pegue o `git.exe` mais recente em `%LOCALAPPDATA%\GitHubDesktop\app-*\resources\app\git\cmd\git.exe`.
- Mostre `status --short` e `log --oneline` antes de enviar.
- Se houver alterações não commitadas, avise e não faça commit por conta própria neste comando.
- Rode `push` na branch atual e confirme o resultado.
